# Luma Brand Assets

This folder contains the supplied Luma brand asset pack.

## Files

| File                         | Use                                                                                 |
| ---------------------------- | ----------------------------------------------------------------------------------- |
| `luma-logo-primary.svg`      | Primary horizontal lockup for light backgrounds.                                    |
| `luma-logo-dark.svg`         | Horizontal lockup presented on an ink background.                                   |
| `luma-symbol-gradient.svg`   | Standalone gradient symbol for product UI, launch screens, and high-impact moments. |
| `luma-symbol-mono-ink.svg`   | Single-color ink symbol for masks, stamps, and quiet UI contexts.                   |
| `luma-symbol-mono-white.svg` | Single-color white symbol for dark surfaces.                                        |
| `luma-wordmark-ink.svg`      | Ink wordmark without the symbol.                                                    |
| `luma-app-icon.svg`          | Light app icon tile.                                                                |
| `luma-app-icon-dark.svg`     | Dark app icon tile.                                                                 |
| `luma-brand-tokens.css`      | CSS custom properties for the brand palette and primary gradient.                   |
| `luma-brand-board.png`       | Visual reference board for lockups, palette, and brand pillars.                     |

## Notes

- The wordmark is path-based, so it does not require a font file to render.
- Use numeric brand tokens from `luma-brand-tokens.css` instead of retyping colors in product code.
- Keep newly added variants documented here and in `docs/brand.md`.
