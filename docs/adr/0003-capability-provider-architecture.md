# Capability-based Provider Architecture

Accepted. Knowledge, Work, and Code capabilities are provider-neutral Interfaces with provider Adapters behind them: Notion is canonical for meeting knowledge, Linear is canonical for executable work, and GitHub is canonical for code and pull requests. GitHub Issues remain a compatibility surface through the Dayova Linear sync. Meeting Intelligence emits provider-independent Follow-up Intents and never depends on provider SDK, MCP, or plugin response types.
